# Reference study and art direction

Use the current brief and actual footage. Establish a visual target before searching
for random textures. This workflow is an original working method informed by the
artist resources in sources.md, not a quotation from a single studio's process.

## Build a reference breakdown

Pick references for specific questions. A polished spell provides composition; a
real spark shower provides motion; the current place provides the camera and value
context. Record links and timecodes so a later comparison can use the same evidence.

| Record | What to observe |
|---|---|
| Event | What triggers the effect and what the viewer learns |
| View | Camera angle, distance, lens, background, and subject size |
| Key moments | Start, major changes, peak, breakup, end; seconds or frames with fps |
| Shape | Outer contour, negative spaces, leading edge, direction, symmetry |
| Hierarchy | Brightest area, sharpest area, coverage, supporting masses |
| Motion | Paths, spacing, acceleration, pauses, lag, inherited movement |
| Material | Expansion, rolling, tearing, flickering, dripping, or fragmentation |
| Exit | What stops first, what continues, and what disappears last |

Do not infer an exact emitter count, mesh, blend mode, or shader from a finished
video. Label implementation ideas as hypotheses. A frontal flipbook and a mesh can
look similar from one angle. Compare another angle before deciding.

Inspect the actual content when possible. If only an article, thumbnail, transcript,
or course outline is available, name that evidence and limit the conclusions.
Do not state that a paid lesson was watched based on its public curriculum.

## Translate to an effect brief

Write one sentence for the action and a few constraints for its visual language.
For example: "a compressed crescent opens into a jagged cut and leaves a thin torn
tail." This defines a shape and a motion without prescribing a texture library.

Record three lists: retain from the reference, adapt to this project, and omit.
Match subject-relative size and on-screen coverage before copying stud measurements.
Match the relative timing of important events before copying a total duration.

If the request permits creative choices, consider distinct silhouette/thumbnails:
one narrow and directional, one broad and weighty, one restrained and symbolic.
Choose for the gameplay read and theme. Do not build three full systems to decide.
Ask when the choice changes the user's stated direction or gameplay behavior.

## Design a beat and layer sheet

Use templates/effect-plan.md. Tie every layer to an event or time interval. Decide
which layer leads the viewer at each beat and which layers are quiet. Mark the
moment the player can clearly read the body or floor again after the peak.

For directional effects, sketch the flow in the object's local frame and identify
where it becomes world-space. For a slash, locate the blade base and tip and mark
the actual contact. For an eruption, locate the vent and ground surface. For a
healing aura, locate the affected target and state transition.

Do not disguise the same radial explosion with a new hue for every material.
Variation should affect silhouette, motion, edge quality, and decay where relevant.

## Review like an art pass

1. Watch once at normal speed without pausing. Write the first visible defect.
2. Find the interval and layers causing that defect. Mute support layers to isolate it.
3. Compare matching moments in the reference and the effect at comparable scale.
4. Write a hypothesis and a specific edit: "the expansion reaches full radius too
   slowly; move most of the travel into the first third of the current interval."
5. Replay the full action. A better still can produce worse motion.

Useful passes: silhouette only, grayscale, no post effects, no audio, individual
layers, and full context. These are diagnostic views; the actual game view decides
the final result. Preserve earlier versions to make A/B comparisons meaningful.

Avoid numerical quality scores without criteria or evidence. "Looks professional"
is not a review note. Name what reads well, what fails, and which capture proves it.
