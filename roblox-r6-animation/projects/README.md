# Project history

Raw history of the projects this skill was built on. The skill does not load this folder: every lesson that holds for any R6 project is already a rule, with its reason and numbers, in `SKILL.md` and `references/`. Read it only to trace where a rule came from.

- `review-log.md` - the dated review log: requests, verdicts and the fix for each, quoted as they were given.
- `case-notes/` - snapshots of `SKILL.md` and the references as they were before the universal rewrite, with the project names, dates and quotes they carried.

The worked examples from these projects are in `scripts/examples/`.
