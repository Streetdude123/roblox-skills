# Project style and review history

Use this file only for Lepy or DIO and The World work. Treat the log as historical feedback about named clips. The current request decides the style; a correction supersedes the earlier decision for that clip. These notes are not engine facts or universal animation rules.

## Current project preferences

- Author through the existing Poser workflow when working in a place that uses it.
- Keep a simple summon small. Add a cutscene only when requested.
- Match the provided canon reference before adding dramatic gestures.
- For the recorded DIO setup use the stand clip as the movement reference and lead it with the user. Recheck the lead time and retargeting on the current rig.
- Keep the pointing pose planted when the request calls for stillness.
- The latest recorded ZA WARUDO revision uses a crouched X followed by a wide V; it supersedes the quiet one-hand version. Keep the requested road roller cutscene beats aligned with the current Config. See the recorded poses below.
- Review from the player camera and inspect the actual motion before claiming completion.
- Work in one authoring thread. Do not turn clip creation into a review swarm.
